# Wispr Flow onboarding capture

Captured from Wispr Flow 1.78 (build 4124) on a physical iPhone 16 Pro running iOS 26.6.1 on November 1, 2026.

## Capture set

The numbered PNG files are the complete onboarding sequence, followed by the first authenticated home screen:

- `01`–`08`: introduction, personalization, sign-in, and alternate sign-in pages
- `09`–`15`: post-login setup and iOS keyboard/full-access configuration
- `16`–`30`: microphone permissions and the typing, formatting, and whisper exercises
- `31`–`37`: wrap-up, privacy, languages, default style, notifications, and desktop offer
- `38`–`41`: referral survey, completion screen, and two-week Pro Trial offer
- `42-flow-home.png`: first Flow home screen after onboarding

There are 42 curated screenshots in total. The set includes the native iOS microphone and notification permission dialogs, keyboard picker, live transcription states, and completed practice results.

`contact-sheet.png` shows the entire sequence in a 6 × 7 grid. `wispr-onboarding-demo.mp4` is a 77.4-second autoplay walkthrough, holding each page for about 1.8 seconds.

The `_transitions` directory preserves duplicate or in-motion captures that were excluded from the curated sequence. Apple authentication was completed manually by the device owner; no authentication dialog or credentials were recorded.
