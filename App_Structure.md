Here's how the Wispr Flow iOS app is structured, based on the 39 flows Mobbin lists. The nesting matches the indentation on the page.

**Wispr Flow (iOS): flow structure**

- **Onboarding** (21 screens)
  - Setting up keyboard (14 screens)
  - Completing account setup (11 screens)
    - Changing language
- **Home**
  - Open an app
  - Transcript information
  - Copying a transcript
  - Regenerating a transcript
  - Giving a feedback (transcript model)
  - Turning on Flow
- **Dictionary**
  - Adding a word to dictionary
  - Updating a word
  - Deleting a word
- **Snippets**
  - Adding a snippet
- **Style**
  - Changing a default sound
- **Scratchpad**
  - Creating a note
    - Renaming a title
  - Searching notes
  - Syncing scratchpad
- **Copying an invitation link**
- **Unlock Flow on computer**
- **Reporting an issue**
- **Account**
  - Editing profile
  - Manage plan
  - Reporting an issue (Account)
  - Logging out
  - Deleting account
- **Settings**
  - Choosing dictation languages
  - Setting up flow disable
  - Turning off audio
- **Logging in**
- **Live Activities**

Mobbin shows screen counts only for the three Onboarding flows. I only have flow names, not the text on each screen, because the screens need a Pro account. If you open a flow while signed in, I can pull the text from its screens too.
